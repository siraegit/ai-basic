Part 1 · 비지도학습과 군집화
비지도학습과 군집화(Clustering)
정답(레이블) 없이 데이터 스스로 패턴을 찾는 학습 방식. 비슷한 것끼리 묶는 군집화가 대표적이다.
🔍
비지도학습 (Unsupervised Learning)
입력 데이터에 대한 레이블 없이 학습. 데이터의 전체적 특성을 분석해 관계·패턴을 스스로 발견한다.
✽ 군집화(Clustering): 비슷한 특성을 가진 데이터끼리 그룹으로 묶는 것
🛍️
고객 세분화
구매 패턴이 비슷한 고객을 그룹화해 맞춤 마케팅
🖼️
이미지 압축
비슷한 색상을 군집화해 대푯값으로 용량 축소
🧬
유전자 분석
유사성 기반으로 질병 관련 유전자 그룹 식별
🚨
이상 탐지
정상 거래 군집에서 벗어난 금융 사기 탐지
🔑 분류(지도학습) vs 군집화(비지도학습)
구분 분류 (Classification) 군집화 (Clustering)
레이블✅ 있음❌ 없음
목적미리 정의된 그룹에 배정새로운 그룹 발견
학습 방식지도학습비지도학습

⚠️ 헷갈리지 말자!
분류는 '이 데이터가 어느 그룹?' 을 판별하는 것이고,
군집화는 '어떤 그룹이 있는지' 를 발견하는 것이다.
Part 1 · k-평균 알고리즘
k-평균 알고리즘 (k-Means)
군집화에서 가장 널리 사용되는 알고리즘. 데이터를 k개의 군집으로 묶고 각 군집의 중심점(Centroid)을 반복 계산한다.
📐 k-평균 알고리즘 4단계
①
중심점 초기 설정
k개의 군집 중심점(Centroid)을 임의로 설정한다.
초기화
②
군집 할당
각 데이터를 가장 가까운 중심점이 속한 군집에 할당한다. 거리 계산: 유클리드 거리
거리 계산
③
중심점 재계산
각 군집에 속한 데이터들의 평균 위치로 중심점을 이동한다.
평균 이동
④
수렴까지 반복
중심점의 변화가 없을 때까지 ②~③을 반복한다. 더 이상 이동이 없으면 군집화 완료!
수렴 완료
⚠️ k값 선택의 중요성
k값이 너무 작으면 → 데이터가 과도하게 단순화
k값이 너무 크면 → 군집이 지나치게 세분화
→ 적절한 k값 탐색 방법: Elbow Method 등
⚠️ 초기 중심점 설정의 영향
초기 중심점 위치에 따라 최종 군집 결과가 달라질 수 있다.
→ 여러 번 실행해 최적 결과를 선택하는 것이 중요하다.

Part 2 · 알고리즘 선정
피어슨 상관계수 (Pearson Correlation)
두 변수 사이의 선형 관계 강도를 -1~1 사이 수치로 나타내는 지표. 선형 회귀 알고리즘 선정의 핵심 근거가 된다.
상관계수 범위 해석
±0.9 이상매우 높은 선형 상관관계
±0.7 ~ ±0.9높은 선형 상관관계
±0.4 ~ ±0.7다소 높은 선형 상관관계
±0.2 ~ ±0.4낮은 선형 상관관계
±0.2 미만선형 상관관계 없음
양수(+): 한 값 ↑ → 다른 값 ↑  /  음수(-): 한 값 ↑ → 다른 값 ↓
🍊 감귤 당도 예측 — 속성별 상관계수
속성 상관계수 해석
평균 기온-0.844높은 음의 상관관계 ✅
최고 기온-0.821높은 음의 상관관계 ✅
최저 기온-0.808높은 음의 상관관계 ✅
일교차-0.512다소 높은 상관관계 ✅
일조율-0.315낮은 상관관계
강수량-0.074상관관계 없음 ❌
→ 평균·최고·최저 기온, 일교차가 당도와 선형 관계 → 다중 선형 회귀 선정
양의 상관관계 (r ≈ +0.9)
음의 상관관계 (r ≈ -0.8)
무상관 (r ≈ 0)
Part 3 · 모델 생성 및 성능 평가
왜 훈련 데이터와 테스트 데이터를 나눠야 할까?
모델의 성능을 올바르게 평가하고 일반화 능력을 확보하기 위해 반드시 분리해야 한다.
📊 데이터 분리 비율
훈련 데이터 70%
테스트 30%
일반적으로 7:3 ~ 8:2 비율로 분리
📚 훈련 데이터 (Training Data)
모델이 패턴과 규칙을 학습하는 데 사용
🧪 테스트 데이터 (Test Data)
훈련된 모델이 실전에서 얼마나 잘 작동하는지 검증
💡 비유: 족보 문제만 외운 학생은 새 문제를 못 푼다.
훈련 데이터 = 족보 / 테스트 데이터 = 실전 시험
과소적합 (Underfitting)
모델이 너무 단순 → 훈련 데이터 패턴도 못 학습
✅ 일반화 (Generalization)
훈련·새 데이터 모두 잘 작동하는 이상적 상태
과적합 (Overfitting)
훈련 데이터에만 최적화 → 새 데이터 예측 나빠짐
→ 테스트 데이터로 과적합 여부 확인!
📌 테스트 데이터를 반복 사용하면 테스트 데이터에도 과적합될 수 있다.
→ 교차 검증(Cross Validation)으로 보완한다.
Part 3 · 모델 생성 및 성능 평가
교차 검증 (Cross Validation)
테스트 데이터를 반복 사용하면 과적합의 원인이 된다. 이를 방지하기 위한 검증 방법이다.
홀드아웃 교차 검증 (Hold-out)
장점: 빠르고 간단
단점: 데이터 분할 방식에 따라 결과가 달라질 수 있음
k-fold 교차 검증 (5-fold 예시)
장점: 안정적이고 신뢰성 높은 성능 평가
단점: 학습을 k번 반복해 시간이 더 걸림
Part 3 · 회귀 모델 성능 평가
회귀 모델의 성능 평가 지표
예측값과 실제값의 오차를 기반으로 모델 성능을 수치화한다.
결정 계수 (R²) 1에 가까울수록 좋음
모델의 절대적인 설명력을 0과 1사이의 비율로 나타낸 지표
평균제곱오차 (MSE) 0에 가까울수록 좋음
오차를 제곱하여 평균한 값으로, 큰 오차를 잡아내는 데 민감
평균제곱근오차 (RMSE) 0에 가까울수록 좋음
MSE에 루트를 씌워, 실제 데이터와 동일한 단위로 직관적 해석이 가능
평균절대오차 (MAE) 0에 가까울수록 좋음
오차 절댓값의 평균으로, 이상치(노이즈)의 영향에 둔감하고 직관적

분류 모델의 성능 평가 지표
혼동 행렬의 TN, FP, FN, TP를 조합해 다양한 성능 지표를 계산한다. 모두 0~1 사이, 1에 가까울수록 좋다.
정확도 (Accuracy)
전체 중 올바르게 분류한 비율
(85+7)/100 = 0.92
⚠️ 클래스 불균형 시 신뢰도 낮음
정밀도 (Precision)
불량으로 예측한 것 중 실제 불량 비율
7/(5+7) = ≈ 0.583
FP를 낮추는 데 집중
재현율 (Recall)
실제 불량 중 불량으로 올바르게 예측한 비율
7/(3+7) = 0.7
FN을 낮추는 데 집중
특이도 (Specificity)
실제 정상 중 정상으로 올바르게 예측한 비율
85/(85+5) = ≈ 0.944

Part 3 · 분류 모델 성능 평가
정밀도 vs 재현율: 상황에 따라 다르다
정밀도와 재현율은 상충 관계(Trade-off)에 있다. 문제 특성에 따라 더 중요한 지표를 선택해야 한다.
정밀도↑ = FP↓ (음성을 양성으로 잘못 분류하는 것 감소)  |  재현율↑ = FN↓ (양성을 음성으로 잘못 분류하는 것 감소)
→ 정밀도를 높이면 재현율이 낮아지는 경향, 그 반대도 동일
📧 정밀도가 더 중요한 경우
스팸 메일 필터
정상 메일→스팸 오판(FP): 중요 메일 못 받아 업무 차질 ❌
스팸→정상 오판(FN): 불편하지만 큰 문제 없음
→ FP를 줄이는 정밀도가 중요
추천 광고
관심 없는 광고 노출(FP) → 사용자 이탈
🏥 재현율이 더 중요한 경우
암 진단 모델
암 환자→정상 오판(FN): 치료 기회 놓침 → 생명 위협 ❌
정상인→암 오판(FP): 추가 검사 비용 발생
→ FN을 줄이는 재현율이 중요
금융 사기 탐지
사기 거래→정상 오판(FN) → 큰 금전 피해
✅ 가장 이상적: 정밀도와 재현율 모두 높은 것. 단, 둘 중 하나만 극단적으로 높고 나머지가 매우 낮으면 바람직하지 않다.
→ 문제의 목적과 상황에 맞게 평가 지표를 선택해야 한다.

FP = 5
실제: 불량
FN = 3
TP = 7
Q1. 정확도를 구하시오.
Q2. 정밀도를 구하시오.
Q3. 재현율을 구하시오.
Q4. 특이도를 구하시오.
정확도
(TN+TP)/(전체) = (85+7)/100 = 92/100
정확도 = 0.92 (92%)
정밀도
TP/(FP+TP) = 7/(5+7) = 7/12
정밀도 ≈ 0.583 (58.3%)
재현율
TP/(FN+TP) = 7/(3+7) = 7/10
재현율 = 0.7 (70%)
특이도
TN/(TN+FP) = 85/(85+5) = 85/90
특이도 ≈ 0.944 (94.4%)
Part 4 · 군집화 모델 성능 평가
실루엣 계수 (Silhouette Coefficient)
군집화 모델의 성능을 수치화하는 지표. 각 데이터가 얼마나 잘 군집화되어 있는지 나타낸다.
📐 실루엣 계수 수식
a(i): 같은 군집 내 다른 데이터들과의 평균 거리
→ 군집 내 응집도 측정 / 작을수록 좋음 (군집이 촘촘)
b(i): 가장 가까운 다른 군집까지의 평균 거리
→ 군집 간 분리도 측정 / 클수록 좋음 (군집이 잘 분리됨)
s(i) ≈ 1
b(i) >> a(i)
같은 군집 내 응집력 높고 다른 군집과 잘 분리됨
→ 군집화 매우 우수 ✅
s(i) ≈ 0
b(i) ≈ a(i)
군집 경계에 위치한 데이터
→ 어느 군집에 속할지 애매한 상태
s(i) ≈ -1
b(i) << a(i)
다른 군집에 더 가까운 상태
→ 잘못된 군집에 배정됨 ❌
📌 데이터 하나의 실루엣 계수가 높다고 전체 군집화가 좋다고 볼 수 없다. 각 군집별 평균이 전체 평균과 크게 벗어나지 않아야 군집화가 고르게 잘 된 것이다.
계산 연습 ✏️ · 군집화 모델
실루엣 계수 직접 계산해보기
아래 데이터를 보고 점 P의 실루엣 계수를 구해보자.
점 P는 군집 A에 소속
군집 A 내 거리:
P→P1 = 3.0   P→P2 = 5.0
P→P3 = 2.0   P→P4 = 2.0
군집 B까지 거리:
P→Q1 = 6.0   P→Q2 = 8.0   P→Q3 = 5.0
Q. 점 P의 실루엣 계수 s(P)를 구하시오.
Step 1: a(P) 계산 — 군집 A 내 평균 거리
(3.0 + 5.0 + 2.0 + 2.0) / 4 = 12/4
a(P) = 3.0
Step 2: b(P) 계산 — 군집 B까지 평균 거리
(6.0 + 8.0 + 5.0) / 3 = 19/3 ≈ 6.33
b(P) = 6.33
Step 3: s(P) 계산
s(P) ≈ 0.53 → 군집화 양호한 편 ✅
Part 5 · 정리
성능 평가 지표 한눈에 비교
모델 종류에 따라 적합한 성능 평가 지표가 다르다.
모델 지표 수식(간략) 좋은 값 특징
회귀 MSE Σ(y-ŷ)²/n 0에 가까울수록 큰 오차에 민감
RMSE √MSE 0에 가까울수록 원래 단위 해석
MAE Σ|y-ŷ|/n 0에 가까울수록 평균 오차 크기
R² 1-SS_res/SS_tot 1에 가까울수록 설명력 비율
분류 정확도 (TN+TP)/전체 1에 가까울수록 클래스 불균형 주의
정밀도 TP/(FP+TP) 1에 가까울수록 FP 줄이기 중요 시
재현율 TP/(FN+TP) 1에 가까울수록 FN 줄이기 중요 시
특이도 TN/(TN+FP) 1에 가까울수록 음성 판별 능력
군집화 실루엣 계수 (b-a)/max(a,b) 1에 가까울수록 -1~1 범위
